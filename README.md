# RISC-V Assembler and Simulator

A Computer Organization project implementing a RISC-V Assembler and Simulator in Python.


---

## Overview

This project consists of:

### Assembler

The assembler converts RISC-V assembly language instructions into machine code.

Features include:

* Instruction parsing
* Opcode translation
* Register handling
* Error checking
* Binary instruction generation

### Simulator

The simulator executes the generated RISC-V machine code and simulates processor behavior.

Features include:

* Instruction execution
* Register updates
* Memory simulation
* Program counter handling
* Output generation

## How to Run

### Clone the Repository

```bash
git clone https://github.com/aasthabwj/RISCV-assembler-and-simulator.git
cd CO-group-project-046
```

---

## Running the Assembler

Move into the assembler folder:

```bash
cd assembler
```

Run the required assembler file:

```bash
python assembler1.py
```

You can similarly run other assembler versions if needed.

---

## Running the Simulator

Move into the simulator folder:

```bash
cd simulator
```

Run:

```bash
python simulator.py
```
